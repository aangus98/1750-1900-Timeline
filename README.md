# 1750-1900-Timeline

Interactive timeline of major historical events from 1750 to 1900.

## Run locally

Open `/home/runner/work/1750-1900-Timeline/1750-1900-Timeline/index.html` directly in a browser.

## Features

- Year slider from 1750 to 1900
- Clickable event markers on the timeline track
- Event list filtered up to the selected year
- Current/latest visible event highlight
